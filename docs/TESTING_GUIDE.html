1. Test Environment & Demo Accounts

AQUACAST operates entirely client-side with full offline PWA capabilities. Test accounts carry different permission scopes:

Role Demo Username Password Authorized Scope & Features
Administrator admin admin123 Unrestricted provincial view; tariff configuration; model evaluation sandbox; broadcast announcements; dataset snapshot recovery.
Station User bagocity station123 Scoped strictly to Bago City (NO-01); Station Forecast Guide; Contact Administration channel; anomaly inquiries.
Station User dumaguetecity station123 Scoped strictly to Dumaguete City (NOR-10).

Module 1: Authentication & Role Isolation

TC-AUTH-01: Role-Based Sign-In & Navigation Scope

TC-AUTH-01

Steps to execute:

  1. Navigate to the login screen. Sign in as bagocity / station123.
  2. Review available sidebar items, the topbar station selector, and bottom navigation.
  3. Sign out via the Account menu and sign in as admin / admin123.
Expected Result: Station user sees only their municipality's data and cannot access Admin settings or broadcast composers. Admin sees full provincial controls, tariff tools, and evaluation tabs. Both screens show prototype disclaimers.

Module 2: Typography, Visual Appeal & Dark Mode

TC-UI-01: Title Prominence & Visual Hierarchy

TC-UI-01

Steps to execute:

  1. Navigate through Dashboard, Consumption records, and Forecasting.
  2. Observe the topbar current page title, the main h1 header, and the uppercase eyebrow badges.
Expected Result: Topbar title is prominent ($22\text{px}$) and serves as a bold section indicator. Main page titles scale smoothly ($32\text{px} - 44\text{px}$) in clean modern system typography. Eyebrows render as distinct teal badges.

TC-UI-02: Dark Mode Inversion & High Contrast

TC-UI-02

Steps to execute:

  1. Click the 🌙 button in the topbar (or select Dark Mode in the Account menu).
  2. Inspect metric cards, table rows, input fields, dropdown menus, modals, and charts.
Expected Result: Background transitions to deep slate/navy (#0b131d / #141f2c). Headings, numbers, and labels become crisp off-white (#ffffff / #e2e8f0) and muted slate (#94a3b8). No dark-on-dark text occurs anywhere. Charts repaint dynamically.

Module 5: Drag-and-Drop CSV Import & Dataset History

TC-IMP-01: Drag-and-Drop Import & "Overview" Button Fit

TC-IMP-01

Expected Result: File validates and updates the dataset. In the history card, the "Overview" button fits cleanly inside the card box on the right. It does not stretch across the card or cause any horizontal page overflow. Clicking it displays snapshot records.
